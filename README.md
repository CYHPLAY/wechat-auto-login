# wechat-auto-login

微信 PC 版开机自启自动登录工具 —— **先检测绿色"进入WeChat"按钮是否就绪，再自动点击**，配合微信"自动登录"实现打开即登录。

## 功能

- 开机自启微信
- **检测之后再点击**：登录窗出现后，先用"取色"确认绿色"进入WeChat"按钮已真正渲染就绪，**按钮没就绪时鼠标完全不动、不空点**；检测到绿色后才点击，实测**通常 1 次即进入**
- **取色而非识图**：只读按钮区域一小簇像素（9×3 共 27 个点）的颜色判断是否为微信绿，**不截屏、不保存图片、不做图像/模板匹配**
- **点击后校验**：确认渲染窗由竖版（登录）变为横版（主界面）才算成功；万一没进入则重新检测再点，默认最多补点 5 次
- **鼠标自动归位**：仅在真正点击时把指针移到按钮上，登录完成后移回原位，尽量不打扰你的操作
- **不挑界面语言、驻留也能唤起**：按"微信进程 + 自绘渲染窗"定位，中文"微信"/英文"WeChat"通吃；微信关窗后进程驻留托盘、没有可见窗口时会自动重新唤出登录窗，不会空等
- **零第三方依赖**（纯 PowerShell + Windows user32/gdi32 API）
- **分辨率 / DPI 自适应**：按钮定位采用窗口内相对比例，不写死屏幕坐标
- **一键部署 / 一键卸载**：`setup.ps1` 自动识别微信路径与物理分辨率；`uninstall.ps1` 干净移除自启

## 原理

微信登录界面是自绘 UI（MMUI/Qt），系统里**没有标准按钮句柄、查不到按钮的"可点"状态，也不接受后台消息注入**，只能通过真实鼠标输入触发。脚本流程：

1. 启动 / 唤起微信：进程不在则启动；进程驻留托盘但没有可见窗口时，再次运行 exe 唤出登录窗（单实例，不会多开）
2. 快速轮询定位竖版登录窗（属于微信进程、可见、含 `MMUIRenderSubWindowHW` 渲染子窗口且为竖版；按进程与渲染窗定位，**不依赖窗口标题语言**），并等窗口矩形稳定
3. **取色检测按钮就绪**：在按钮区域（按窗口比例定位，约渲染区 49.8%、77.3% 为中心）用 `GetPixel` 采样 9×3 个像素，统计"微信绿"（绿色通道明显高于红/蓝）占比，达到阈值（默认 30%）才判定按钮已渲染。此阶段**不移动鼠标**；采样能避开按钮中央白色文字的干扰
4. 记住鼠标位置、把窗口置前、产生一次 hover
5. 真实鼠标点击一次（SetCursorPos + mouse_event）
6. 轮询校验是否变为横版主界面：是则成功；否则回到第 3 步重新检测再点（默认最多 5 次）
7. 把鼠标移回原位并退出

> 提示：请在微信登录时勾选**"自动登录该设备"**（手机端），点击"进入WeChat"后即可免手机确认。

## 使用

### 一键部署（推荐）

```powershell
powershell -ExecutionPolicy Bypass -File setup.ps1
```

自动完成：识别微信路径 → 识别物理分辨率 → 生成脚本（UTF-8 带 BOM）→ 配置开机自启。

### 手动

```powershell
# 运行一次主脚本（立即自动登录）
powershell -NoProfile -ExecutionPolicy Bypass -File wechat_autologin.ps1

# 安装开机自启
powershell -ExecutionPolicy Bypass -File install_autostart.ps1
```

### 卸载（移除开机自启）

```powershell
powershell -ExecutionPolicy Bypass -File uninstall.ps1
```

## 参数

`wechat_autologin.ps1`：

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `-WeChatExe` | `D:\WeChat\Weixin\Weixin.exe` | 微信程序路径（`setup.ps1` 会自动识别并替换） |
| `-WeChatDir` | `D:\WeChat\Weixin` | 微信工作目录 |
| `-TimeoutSec` | `30` | 等待登录窗 / 绿色按钮的超时（秒） |
| `-BtnX` / `-BtnY` | `0.498` / `0.773` | "进入WeChat"按钮中心相对位置（点不准时可微调） |
| `-GreenRatio` | `0.30` | 采样像素中绿色占比达到该值即判定按钮就绪（误判可调大，检测不到可调小） |
| `-MaxRetries` | `5` | 检测到绿并点击后，若没进入主界面的最多补点次数 |
| `-MinReadyMs` | `250` | 登录窗矩形稳定后至少等多久再开始取色（毫秒） |
| `-RestoreMouse` | `$true` | 登录完成后是否把鼠标移回原位 |

`install_autostart.ps1`：

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `-WeChatExe` | `D:\WeChat\Weixin\Weixin.exe` | 微信程序路径 |

## 注意事项

- 脚本使用**真实鼠标输入**，但**只在检测到绿色按钮、真正点击的瞬间**移动指针，检测阶段鼠标不动；登录完成后自动移回原位（可用 `-RestoreMouse $false` 关闭归位）。
- "自动登录"需先在**手机端**开启：登录电脑微信时，在手机确认页勾选"自动登录该设备"。
- 只建议在**自己的常用电脑**上启用自动登录。
- 按钮定位使用**相对比例**，不同分辨率 / DPI 的机器可直接使用；若个别微信版本按钮位置有偏差，可用 `-BtnX`/`-BtnY` 微调；绿色判定阈值可用 `-GreenRatio` 微调。
- **检测方式与隐私**：脚本不截屏、不保存任何图像、不做图像识别，仅调用 `GetPixel` 读取按钮区域 27 个像素的颜色值来判断按钮是否变绿，不读取聊天内容或其他界面信息。
- **耗时说明（实测）**：绿色按钮一般在微信启动后约 1～2 秒渲染就绪，脚本检测到后立即点击（通常 1 次命中）；点击之后微信还要用数秒完成登录验证、加载主界面（**这一段与网络/机器性能有关，脚本无法压缩**），整体从启动到进入主界面约 4～6 秒属正常现象。

## 编码说明

- 脚本含**中文注释**，需使用 **UTF-8（带 BOM）** 编码保存。
- `setup.ps1` 生成的 `wechat_autologin.ps1` **自动带 BOM**，Windows PowerShell 5.1 下不会乱码。
- 若你手动编辑后在 PowerShell 5.1 打开出现乱码：用记事本"另存为"→ 编码选 `UTF-8（带 BOM）`；PowerShell 7 / VS Code 通常无此问题。
