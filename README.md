# 微信开机自动登录

开机进 Windows 后，自动帮你打开微信、点掉绿色的“进入 WeChat”按钮，直接进到微信主界面。

- 不用装任何环境或依赖
- 分辨率、缩放 (DPI)、微信装在哪个盘都自动适配
- 只开一个微信，不会多开

## 使用

1. 双击 `WeChatAutoLoginSetup.exe`
2. 输入 `1` 回车（安装 / 修复）

就好了，下次开机自动登录微信。

菜单里还有：

- `2` 立即测试：马上模拟开机跑一次
- `3` 卸载：恢复到安装前的样子
- 顶部显示开机启动项数量；如果不止一个（会导致多开），按 `1` 就会自动清理，只保留一个

## 小提示

- 第一次需要先在手机微信上勾选“自动登录该设备”。
- 要进到已解锁的桌面才会点击，锁屏状态下不执行。
- exe 没有数字签名，弹出 SmartScreen 时点“更多信息 → 仍要运行”。
- 点完按钮微信还要联网几秒才进主界面，属正常现象。

## 卸载

双击 exe 输入 `3`；或运行安装目录里的 `uninstall.ps1`。

## 源码文件（可忽略）

除 `WeChatAutoLoginSetup.exe` 外，`.ps1` 是脚本、`Installer.cs` 是 exe 源码、`tests/` 是测试。只想使用的话这些都不用管。
